# Velar IA Landing

Landing premium para Velar IA creada con React, TailwindCSS y Framer Motion.

## Editar integraciones

Los placeholders principales estan en `src/data.js`:

- `WEBHOOK_URL`: URL donde se envia el formulario.
- `WHATSAPP_URL`: link del boton flotante y CTA de WhatsApp.

## Comandos

```bash
npm install
npm run dev
npm run build
```

## Estructura

```text
src/
  App.jsx
  data.js
  styles.css
  components/
    ContactForm.jsx
    DashboardMockup.jsx
    Logo.jsx
    SectionHeader.jsx
```
